# 디자인 규칙

경로는 웹이면 `web/`, iOS 면 `mobile/` 기준이다. 화면은 이미 다 그려져 있다. 이 문서는 누가 UI 를 만지더라도 같은 결과가 나오게 하는 규칙이다.
통합 작업은 UI 를 건드리지 않으므로 대개 읽을 일이 없다. 화면을 고치거나 새로 만들 때 읽는다.

## 한 줄

모눈종이 위의 픽셀. 따뜻한 종이색 팔레트는 그대로 두고, 글꼴·모서리·그림자·아이콘을 픽셀로 맞춘다 (2026-09-16 픽셀 리디자인).

## 토큰 (`app/globals.css`)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `paper` / `paper-deep` | `#f5f2ea` / `#ebe6da` | 바탕, 눌리지 않은 선택지 |
| `card` | `#fffdf8` | 카드 |
| `ink` / `ink-soft` / `muted` | `#1f1c17` / `#4a463f` / `#7d786d` | 본문 / 보조 / 설명 |
| `line` / `line-strong` | `#e0dbcf` / `#c9c2b2` | 카드 테두리 / ghost 버튼 테두리 |
| `accent` / `accent-ink` | `#d8542a` / `#b5431f` | **힌트 버튼과 포커스 표시만** |
| `good` / `good-soft` | `#2e7a4d` / `#e3f0e7` | 사용한 표현 체크 |
| `warn` | `#b3401e` | 30초 남은 타이머, 에러 문구, 통화 끝내기 |
| `grid` | `#e9e4d8` | 바탕 24px 모눈 선 |

색은 이 표 밖에서 새로 만들지 않는다. 그라디언트는 쓰지 않는다. 그림자는 흐림 0의 잉크색(`shadow-px` 4px, `shadow-px-sm` 2px)뿐이다.

## 타이포

- 글꼴은 하나다: 갈무리(Galmuri11, OFL-1.1, npm `galmuri`, `next/font/local`). 12px 격자로 그린 픽셀 글꼴이라 **크기는 6의 배수만** 쓴다(레티나에서 정수배). 12 · 18 · 24 · 30 · 36 · 42.
- 영어 표현·숫자·화면 제목: `font-display` (갈무리 Bold). 표현 카드 36~42px, 타이머 36px, 홈 제목 42px.
- UI 문구: 갈무리 Regular. 설명·라벨 12px, 본문 18px. 자간을 건드리지 않는다.
- 발음기호: `font-mono`(시스템) 12px, `muted`. 픽셀 글꼴에 IPA 글리프가 없다.
- 굵기는 regular 와 bold 둘뿐이다.

## 공용 부품 (`components/ui.tsx`)

- `Button` variant: `primary`(ink) · `ghost`(테두리) · `quiet`(글자만) · `accent`(힌트 전용). 한 화면에 accent 는 하나.
- `Card` (`strong` 이면 ink 테두리 = 지금 할 일), `Label`, `Chip`(`done` 이면 good), `Shell`(가운데 560px 컬럼).
- 모서리는 전부 각지다(`rounded-*` 를 쓰지 않는다). 테두리는 2px. 버튼은 `shadow-px-sm` 이고 누르면 2px 내려앉는다. `strong` 카드만 `shadow-px`.

## 통화 화면 (`components/screens/Call.tsx`)

화상회의 구도다. 무대가 주인공이고 연습 내용은 오른쪽 패널에 있다. 무대 부품(이름표·툴바·아이콘)은 `components/CallStage.tsx` 에 있고 폰 파트너 화면과 같이 쓴다.

- 무대(`stage` 클래스, 배경 `#221f1a`)는 어두운 종이색, 각진 모서리, 세로를 다 쓴다. 상대가 크게, 나는 우상단 PIP(224×140, 흰 테두리 20%), 아래 88px 툴바. 툴바는 마이크·카메라·화면 공유(공유 API 가 있는 데스크톱 브라우저만) 아이콘 버튼이 가운데, 통화 끝내기(전화 끊기 아이콘)는 오른쪽 `warn` 색(어두운 무대 위라 ink 대신).
- 이름표: 좌하단 "파트너 · 폰", PIP 안 "나". 마이크가 꺼지면 아이콘에 빗금(`#f0a58a`), 카메라가 꺼지면 카메라 아이콘이 하나 더 붙는다. 상대 상태는 RTM 에서 온다(`onPartner`). 통화 중에는 좌상단에 초록 점 상태 알약(화면 공유 중이면 "내 화면을 공유하는 중 · 파트너 폰에 보여요").
- 카메라가 꺼진 자리(`CameraOffTile`): 검은 화면이나 멈춘 마지막 프레임 대신 카메라 빗금 아이콘. 내 PIP 는 아이콘만, 상대 자리는 아이콘 + "카메라 꺼짐". 상대 쪽은 RTM 상태로 켠다. 폰 앱도 같다(`CameraOffView`).
- 상대가 없을 때 무대 안에 사람 픽셀 아이콘 칸 하나와 상태 문구. 상태는 `data-state` 로만 바뀐다: `connecting` → `waiting`(초대 카드) → `connected`(타이머가 흐른다) → `partner-left` / `ended`. 껍데기는 `unavailable`, 실패는 `error`.
- 오른쪽 패널(360px, 1024px 아래에서는 무대 아래로): 초대 카드(대기·상대 나감일 때만. QR + 방 코드 + "초대 링크 복사") → 오늘의 표현(영어 `font-display` 24px + 뜻 12px, 통화 중이면 ink 테두리) → 힌트 버튼(accent, 맨 아래).
- 힌트는 모달이 아니라 무대 아래쪽 자막 카드(560px)로 뜬다. 상대 얼굴을 보면서 읽는다. 듣기·읽었어요, Esc.
- `?preview=connected` 로 연결된 상태를 영상 없이 볼 수 있다. 6초에 상대 마이크 꺼짐, 9.5초에 카메라 꺼짐, 13초에 둘 다 켜짐이 들어 있다.

## 폰 파트너 화면 (`components/screens/Partner.tsx`)

초대 링크(`?room=`)로 열리면 홈 대신 이 화면이다. 둘뿐이다. 들어가기(제목 "파트너", 방 코드 카드, "마이크 켜고/끄고 들어가기" 토글, 검정 "들어가기", 권한 안내 한 줄)와 통화(전체 화면 무대: 상대 전체, 우상단 내 카메라 96×128(가로 128×96), 좌상단 이름표 "데스크톱", 아래 마이크·카메라·나가기). 데스크톱이 화면을 공유하면 공유 화면이 크게, 데스크톱 얼굴이 왼쪽 위에 작게 뜨고, 작은 쪽을 누르면("눌러서 크게") 서로 바뀐다. 폰을 눕히면 가로 배치다. 표현 카드와 힌트는 없다. 파트너는 얼굴만 보여주는 쪽이다.

## iOS 파트너 앱 (`mobile/Partner/ContentView.swift`)

같은 토큰을 `Theme.swift` 에 그대로 옮겼다. 글꼴은 같은 갈무리 ttf 를 `Partner/Fonts/` 에 번들한다(`UIAppFonts`, 라이선스 `Galmuri-OFL.txt`). 모눈 바탕은 `GridPaper`, 카드·버튼은 `PixelFrame`, 아이콘은 `PixelIcon.swift`(웹과 같은 격자). 라이트 모드로 고정한다(`preferredColorScheme(.light)`). 화면은 둘뿐이다. 들어가기(제목 "미팅방 입장", 미팅 코드 입력 카드, "마이크 켜고/끄고 들어가기" 토글, 검정 "미팅 참여하기")와 통화(무대 + 우하단 내 카메라 96×128 + 아이콘 달린 마이크·카메라·나가기). 가로로 눕히면 무대가 왼쪽, 상태 줄과 버튼이 오른쪽 세로 줄이다. 상대 마이크·카메라 꺼짐과 화면 공유 중은 상태 줄에 글자로 보인다(RTM). 공유 화면은 웹 파트너 화면처럼 작은 쪽을 누르면 크게 바뀐다.
표현 카드와 힌트는 폰에 없다. 파트너는 얼굴만 보여주는 쪽이다.

## 하지 않는 것

- 카드 안에 카드, 흐린 그림자, 아이콘 세트. 아이콘은 통화 무대의 16×16 픽셀 다섯(마이크·카메라·화면 공유·전화 끊기·사람, `components/CallStage.tsx` 의 `GRIDS`)뿐이고 꺼짐은 같은 그림에 빗금이다. 크기는 16·24·48. 이모지는 힌트 버튼(💡)과 듣기(🔊) 두 곳만.
- 다크 모드. (종이 컨셉이라 라이트 고정)
- 모션 추가. 있는 건 화면 진입 하나뿐이고, `steps()` 계단 움직임이며 `prefers-reduced-motion` 을 존중한다.
