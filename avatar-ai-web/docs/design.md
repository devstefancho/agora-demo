# 디자인 규칙

경로는 이 디렉토리(`avatar-ai-web/`) 기준이다. 화면은 이미 다 그려져 있다. 이 문서는 누가 UI 를 만지더라도 같은 결과가 나오게 하는 규칙이다.
통합 작업은 UI 를 건드리지 않으므로 대개 읽을 일이 없다. 화면을 고치거나 새로 만들 때 읽는다.

## 한 줄

모눈종이 위의 픽셀. 따뜻한 종이색 팔레트는 그대로 두고, 글꼴·모서리·그림자·아이콘을 픽셀로 맞춘다.

## 토큰 (`app/globals.css`)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `paper` / `paper-deep` | `#f5f2ea` / `#ebe6da` | 바탕, 눌리지 않은 선택지 |
| `card` | `#fffdf8` | 카드 |
| `ink` / `ink-soft` / `muted` | `#1f1c17` / `#4a463f` / `#7d786d` | 본문 / 보조 / 설명 |
| `line` / `line-strong` | `#e0dbcf` / `#c9c2b2` | 카드 테두리 / ghost 버튼 테두리 |
| `accent` / `accent-ink` | `#d8542a` / `#b5431f` | **힌트 버튼, 포커스 표시, 대화 중인 Mia 구슬만** |
| `good` / `good-soft` | `#2e7a4d` / `#e3f0e7` | 사용한 표현 체크 |
| `warn` | `#b3401e` | 30초 남은 타이머, 에러 문구, 대화 끝내기 |
| `grid` | `#e9e4d8` | 바탕 24px 모눈 선 |

색은 이 표 밖에서 새로 만들지 않는다(무대 팔레트 `#221f1a` 계열과 구슬 기본색 `#dcd2bd` 는 예외). 그라디언트는 쓰지 않는다. 그림자는 흐림 0의 잉크색(`shadow-px` 4px, `shadow-px-sm` 2px)뿐이다.

## 타이포

- 글꼴은 하나다: 갈무리(Galmuri11, OFL-1.1, npm `galmuri`, `next/font/local`). 12px 격자로 그린 픽셀 글꼴이라 **크기는 6의 배수만** 쓴다(레티나에서 정수배). 12 · 18 · 24 · 30 · 36 · 42.
- 영어 표현·숫자·화면 제목: `font-display` (갈무리 Bold). 표현 카드 36~42px, 타이머 36px, 홈 제목 42px.
- UI 문구: 갈무리 Regular. 설명·라벨 12px, 본문 18px. 자간을 건드리지 않는다.
- 발음기호: `font-mono`(시스템) 12px, `muted`. 픽셀 글꼴에 IPA 글리프가 없다.
- 굵기는 regular 와 bold 둘뿐이다.

## 공용 부품 (`components/ui.tsx`)

- `Button` variant: `primary`(ink) · `ghost`(테두리) · `quiet`(글자만) · `accent`(힌트 전용). 한 화면에 accent 는 하나.
- `Card` (`strong` 이면 ink 테두리 = 지금 할 일), `Label`, `Chip`(`done` 이면 good), `Shell`(가운데 560px 컬럼).
- 모서리는 전부 각지다(`rounded-*` 를 쓰지 않는다). 테두리는 2px. 버튼은 `shadow-px-sm` 이고 누르면 2px 내려앉는다. `strong` 카드만 `shadow-px`.

## 대화 화면 (`components/screens/Talk.tsx`)

화상 튜터 구도다. Mia 의 얼굴이 무대 주인공이고 연습 내용은 오른쪽 패널에 있다. 무대 부품(구슬·이름표·툴바·아이콘)은 `components/TalkStage.tsx` 에 있다.

- 무대(`stage` 클래스, 배경 `#221f1a`)는 어두운 종이색, 각진 모서리, 세로를 다 쓴다. 아바타 비디오가 무대를 채우고, 아래 88px 툴바. 툴바는 마이크 아이콘 버튼이 가운데, 대화 끝내기(전화 끊기 아이콘)는 오른쪽 `warn` 색.
- 얼굴이 오기 전(연결 중, 벤더 준비 중)과 아바타 없이 목소리로만 대화할 때는 무대 가운데에 **Mia 구슬**(`.orb`, 168px 픽셀 원)과 이름·상태 문구가 뜬다. 구슬은 `data-state` 로만 바뀐다: `connecting` 깜빡임 → `live` accent 색으로 숨쉼(`steps()`) → `error` 회색. 얼굴이 붙으면(`onAvatar(true)`) 구슬이 사라지고, 좌상단 초록 점 상태 알약과 좌하단 이름표 "Mia · AI 아바타" 가 뜬다.
- 오른쪽 패널(360px, 1024px 아래에서는 무대 아래로): 껍데기일 때 안내 카드 → 자막(Mia 와 나의 마지막 한 줄씩, 18px) → 오늘의 표현(영어 `font-display` 24px + 뜻 12px, 대화 중이면 ink 테두리, 쓴 표현은 앞에 good 색 ✓) → 힌트 버튼(accent, 맨 아래).
- 힌트는 모달이 아니라 무대 아래쪽 자막 카드(560px)로 뜬다. Mia 얼굴을 보면서 읽는다. 듣기·읽었어요, Esc. 아래에 "Mia는 기다리고 있어요".
- `?preview=live` 로 대화 중 상태(구슬, 자막 세 줄)를 목소리 없이 볼 수 있다.

## 완료 화면 (`components/screens/Done.tsx`)

"세션 완료" 또는 "아직 대화 전". 오늘의 표현 칩(대화 기록에서 쓴 것은 good), 사용한 표현 수 · 대화 시간 · 힌트 수, 접힌 "대화 기록 보기", "홈으로".

## 하지 않는 것

- 카드 안에 카드, 흐린 그림자, 아이콘 세트. 아이콘은 무대의 16×16 픽셀 둘(마이크·전화 끊기, `components/TalkStage.tsx` 의 `GRIDS`)뿐이고 꺼짐은 같은 그림에 빗금이다. 크기는 16·24·48. 이모지는 힌트 버튼(💡)과 듣기(🔊) 두 곳만.
- 다크 모드. (종이 컨셉이라 라이트 고정)
- 모션 추가. 있는 건 화면 진입과 구슬 둘뿐이고, `steps()` 계단 움직임이며 `prefers-reduced-motion` 을 존중한다.
